# Apple Website Clone

Este proyecto es una clonación del sitio web oficial de Apple. El objetivo es practicar y mejorar habilidades en desarrollo web utilizando HTML, CSS y JavaScript. Además, se han utilizado las siguientes tecnologías avanzadas:

- ReactJS para la construcción de interfaces de usuario interactivas.
- Three.js para la creación de gráficos 3D.
- GSAP (GreenSock Animation Platform) para animaciones avanzadas y transiciones suaves.

Estas tecnologías permiten crear una experiencia de usuario rica y dinámica, similar a la del sitio web oficial de Apple.

## Características

- Diseño responsivo
- Navegación interactiva
- Animaciones y transiciones
- Secciones de productos con información detallada

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript

## Instalación

1. Clona el repositorio:
  ```bash
  git clone https://github.com/tu_usuario/apple_website_clone.git
  ```
2. Navega al directorio del proyecto:
  ```bash
  cd apple_website_clone
  ```
3. Abre `index.html` en tu navegador preferido.
